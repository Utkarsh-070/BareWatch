# Security policy

BareWatch is designed to operate without a backend, remote scripts, accounts, analytics, or broad browser permissions.

## Reporting a problem

Do not include cookies, login details, browser-profile files, or private YouTube account information in a report. Use the **Copy safe diagnostics** button on the BareWatch settings page and include only the smallest screenshot needed to demonstrate the issue.

The extension has no dedicated security inbox yet. Report a suspected security issue privately to the repository owner using a contact they have provided. Keep exploit details out of public issues until a fix is available. A monitored contact should be added before a public store release.

## Supported versions

During the private beta, only the newest beta build receives fixes. Public support and update windows will be documented before version 1.0.
